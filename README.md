## Contexte

Ces documents sont des supports d'apprentissage issus de la période de formation 2024–2025. Ils peuvent comporter des exemples ou des étapes à adapter. Leur organisation a été améliorée en novembre 2026 ; les laboratoires n'ont pas été rejoués à cette occasion.

Les variantes d'installation se rapportent à Zabbix 7.2 et Debian 12. Avant une nouvelle installation, choisir une combinaison prise en charge dans la [documentation officielle Zabbix](https://www.zabbix.com/documentation/current/en/manual/installation).

Pour documenter une nouvelle manipulation, préciser les versions utilisées, l'objectif, les étapes effectuées, le résultat observé et les difficultés rencontrées. Distinguer les captures personnelles des illustrations provenant de ressources externes.
